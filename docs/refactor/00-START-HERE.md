## 三条命令

```bash
npm install                    # 首次会重写 package-lock.json,此为预期(G5)
npm run check:node             # 语法
"npm run test:backend"         # 单测
npm run check:api-contract     # 契约与文档对账
```

三条全绿才能开 PR。PR 描述里必须贴门禁输出,并单开一段写「我发现但没做的东西」。

## 领卡方式

一卡一分支一 PR,分支名 `refactor/t07-jobs-runner` 这种形式,从 `refactor/frontend-backend-split` 切出。
依赖关系看卡顶部的**依赖 / 阻塞**字段。T03、T04、T05、T12 无前置,可以第一批并行开。

## 最重要的一条

**卡里没写的不要发明。**

几个 agent 各自为相同概念发明不同名字(`jobId` / `job_id` / `taskId`),是这类重构死法的第一名。所以:列名一律照 `001_init.sql`,事件名与错误码一律从 `@openpet/contracts` 取,状态字符串一律从 `jobs/state-machine.js` 取。

发现卡写错了或漏了:**先改文档,和代码同一个 PR**。不要一声不响地按自己的理解实现。

## 已落地的代码怎么对待

`services/backend/` 下已有的文件(路由器、中间件、桥、`db.js`、`state-machine.js`、`001_init.sql`)是**样板**。
按现状用,不要重写,不要改签名 —— 新文件的风格向它们对齐(tab 缩进、工厂函数 + 注入依赖、纯函数优先)。
