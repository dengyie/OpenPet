# Signed Release Closure Reports

This directory stores release-claim closure audits that combine macOS, Windows, picker, and packaged-runtime evidence into one readiness judgment.

Start with `2026-07-06T16-46-49Z-v1.0.1-rc.3-authenticated-closure-archive-rerun/` for the current best closure archive. The `2026-06-16T15-00-00Z/` and `2026-07-06T16-40-00Z-v1.0.1-rc.3-authenticated-closure/` directories remain historical context.

These closure archives are useful because they preserve the best available cross-platform readiness audit at a point in time. They do not by themselves prove release readiness when the archived result is still `releaseReady: false`, which is the current case.
