# Plugin Community-Source Intake Reports

This directory stores Phase 100 compatibility-first intake reports for candidate third-party plugin archives.

Start with the current archived incompatible candidates: `2026-07-06T10-20-00Z-openpets-plugin-starter/` and `2026-07-06T10-30-00Z-opencode-pets/`. The older `2026-06-18T23-30-00Z-openpets-official/` session remains baseline context.

These reports are useful because they preserve archive provenance and package-model compatibility findings. They do not install, enable, run, sign, publish, or trust a plugin by themselves.
