# Plugin Community-Source Invitation Kits

This directory stores draft outreach packets for finding compatible third-party plugin sources.

Start with `2026-07-06T15-46-14Z-openpets-plugin-starter-outreach/` for the targeted outreach draft. The older `2026-06-18T23-59-00Z-compatible-author-outreach/` archive remains general historical context.

These invitation kits are useful because they preserve outreach drafts and follow-up checklists. They do not by themselves prove an invitation was sent, accepted, or answered with a compatible package.
