# macOS Release Evidence Archives

This directory stores authenticated workflow-artifact imports and companion parser reruns for macOS signing evidence.

Start with `2026-07-06T17-32-13Z-v1.0.1-rc.3-authenticated-artifact-current-parser-rerun/` for the current local interpretation, and use `2026-07-06T16-17-27Z-v1.0.1-rc.3-authenticated-artifact-import/` for the original imported artifact contents.

These archives are useful because they preserve macOS release provenance and parser interpretation. They do not by themselves prove passing signed readiness.
